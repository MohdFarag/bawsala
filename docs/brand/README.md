# Bawsala brand · بوصلة

The mark ("Masar", المسار) is the letter **ب** drawn as a path that rises into an arrow, with its dot below: the first letter of بوصلة, pointing forward. The name is set in **Aref Ruqaa Bold** (SIL Open Font License, [aliftype/aref-ruqaa](https://github.com/aliftype/aref-ruqaa)), converted to outlines in these files.

| File | Use |
| --- | --- |
| `bawsala-logo.svg` / `.png` | Stacked logo: mark above بوصلة |
| `bawsala-logo-horizontal.svg` | Mark beside the name |
| `bawsala-symbol.svg` | Mark only, transparent background |
| `bawsala-icon-dark.svg` | App icon: white mark on teal (used for the Android launcher icon) |
| `bawsala-icon-light.svg` | App icon: teal mark on white |

| Color | Hex |
| --- | --- |
| Teal (main) | `#05473F` |
| Sage (accent, the dot) | `#B2C18F` |
